# 한국 전통혼례 청첩장 사이트 디자인 가이드

> 프로젝트 적용 결정(2026-07-31): 이 문서는 새 디자인 방향의 원본 레퍼런스로 유지합니다. 실제 v18 적용에서는 `00-decisions.md`가 우선합니다. 완자살 창호문과 기존 서사·수평 타임라인·480px 모바일 프레임·은은한 한지 질감은 유지하고, 중앙 카드에는 `sangho-steph-square-tassel.png` 인장을 사용합니다. 전역은 이 문서의 새 팔레트를 적용하되 창호문 재질색은 기존값을 유지하고 타임라인은 테라코타로 변경합니다. 문 이후 오프닝은 현재 이미지, 최종적으로는 복수의 짧은 영상으로 구성하며 RSVP를 포함합니다.

## 1. 문서 목적

이 문서는 2026년 11월 1일 롯데월드 전통혼례장에서 진행하는 한국 결혼식을 위한 모바일 청첩장 사이트의 디자인 기준을 정의한다.

새 사이트는 기존 캐나다 결혼식 청첩장의 코드나 레이아웃을 재사용하지 않는다.

대신 다음 두 가지를 결합한다.

- 기존 캐나다 청첩장의 따뜻한 색감과 차분한 정서
- ONEIR 스타일 사이트의 스크롤 기반 시네마틱 연출

최종 방향은 다음과 같다.

> 은은한 한지 위에서 캐나다에서 시작된 두 사람의 이야기가 세 사람의 가족으로 이어지고, 한국 전통혼례로 연결되는 스크롤 기반 청첩장

### 4.4 색상별 역할

## 5. 한지 질감

### 5.1 기본 원칙

전체 페이지에서 **은은한 한지 질감**을 유지한다.

목표는 사용자가 처음부터 한지를 인지하는 것이 아니라, 화면을 자세히 보았을 때 자연스럽게 종이의 결을 느끼게 하는 것이다.

### 5.2 질감 적용 범위

- 전체 페이지 배경: 적용
- 초대 문구 카드: 적용
- 혼례 정보 카드: 적용
- 사진 갤러리 이미지 자체: 미적용
- 스크롤 영상: 매우 약한 오버레이
- 지도 및 입력 폼: 미적용 또는 거의 보이지 않게 적용

### 5.3 권장 강도

```css
:root {
  --paper-texture-opacity: 0.18;
  --media-paper-overlay-opacity: 0.10;
}
```

화면별 권장 범위:

- 전체 배경: `0.15 ~ 0.22`
- 초대 문구: `0.18 ~ 0.28`
- 영상 위: `0.08 ~ 0.12`
- 전환 장면: 최대 `0.25`

### 5.4 구현 예시

```css
.hanji-background {
  position: relative;
  isolation: isolate;
  background:
    radial-gradient(
      circle at 18% 13%,
      rgba(255, 255, 255, 0.72),
      transparent 30%
    ),
    radial-gradient(
      circle at 79% 84%,
      rgba(162, 98, 73, 0.045),
      transparent 34%
    ),
    #F8F4ED;
}

.hanji-background::before {
  content: "";
  position: absolute;
  inset: 0;
  z-index: -1;
  pointer-events: none;
  opacity: 0.18;
  filter: url("#paperNoise");
  background: #BCAE97;
  mix-blend-mode: multiply;
}
```

### 5.5 주의사항

- 한지 텍스처 이미지를 그대로 반복 타일링하지 않는다.
- 너무 높은 대비의 섬유 이미지를 사용하지 않는다.
- 배경이 누렇게 보이지 않게 한다.
- 영상 위 질감은 화질 저하처럼 보이지 않아야 한다.

## 6. 타이포그래피

### 6.1 기존 폰트

기존 캐나다 청첩장은 커스텀 TTF를 사용했다.

빌드 결과에서 확인된 이름:

```css
font-family: MainFont;
```

정확한 정식 서체 이름은 빌드 결과만으로 확인할 수 없다.

이 서체의 정서는 유지하되, 새 프로젝트에서는 이름이 명확하고 웹에서 안정적으로 사용할 수 있는 서체를 선정한다.

### 6.2 추천 조합

#### 제목 및 감성 문구

우선순위:

1. MaruBuri
2. Gowun Batang
3. Noto Serif KR
4. KoPub Batang
5. 기존 커스텀 MainFont

#### 본문 및 기능 정보

우선순위:

1. Pretendard
2. SUIT
3. Noto Sans KR

#### 영문 장식

우선순위:

1. Cormorant Garamond
2. EB Garamond
3. Libre Baskerville

### 6.3 역할별 폰트

```css
:root {
  --font-display: "MaruBuri", "Noto Serif KR", serif;
  --font-body: "Pretendard", "Noto Sans KR", sans-serif;
  --font-english: "Cormorant Garamond", Georgia, serif;
}
```

- 이름과 Hero: `--font-display`
- 초대의 글: `--font-display`
- 날짜·주소·지도·버튼: `--font-body`
- 영문 장식 문구: `--font-english`

### 6.4 권장 크기

모바일 기준:

```css
--font-hero: clamp(2.5rem, 11vw, 4.5rem);
--font-section-title: clamp(2rem, 8vw, 3.25rem);
--font-story-caption: clamp(1.5rem, 6vw, 2.5rem);
--font-body-large: 1.125rem;
--font-body: 1rem;
--font-small: 0.8125rem;
```

### 6.5 타이포그래피 원칙

- 한 화면에 긴 문장을 노출하지 않는다.
- 시네마틱 구간의 문구는 최대 3줄로 제한한다.
- 영문 대문자에는 넓은 자간을 사용한다.
- 주소와 시간은 감성 폰트가 아닌 고딕체를 사용한다.
- 인장 내부 글자는 별도의 가독성 검수를 진행한다.


```text

2026.11.01
```

### 7.2 추천 인장 형태

우선순위:

1. 원형 인장
2. 라운드 스퀘어 인장

### 7.3 인장 색상

```css

--seal-color-soft: #A26249;
--seal-accent: #B49A62;
```

### 7.4 인장 질감

- 완전히 깨끗한 벡터 로고처럼 보이지 않게 한다.

- 텍스트 가독성은 유지한다.
- 실제 도장보다 과장된 거친 효과는 피한다.

### 7.5 인장 사용 위치

- 로딩 화면

- 날짜 강조
- 일반 콘텐츠 전환점
- 마지막 감사 인사
- Open Graph 이미지

### 7.6 사용 금지

- 모든 섹션 제목 옆에 반복
- 버튼 내부
- 지도 위

## Sequence 05 — 캐나다에서 한국으로

### 화면

- 밴쿠버 풍경
- 구름
- 서울 또는 전통 지붕
- 밴쿠버에서 서울까지 이어지는 선

### 문구

```text
캐나다에서 시작된 우리의 이야기를
이제 한국의 가족과 친구들 앞에서

```

### 모션

```text

    ↓
Seoul
```

- 밴쿠버 풍경이 구름에 가려짐
- 구름이 걷히며 한옥 지붕 등장
- 이 구간부터 전통 적색과 금색 비중 증가

### 구현 선택지

## 15. 반응형 기준

### 모바일 우선

청첩장은 카카오톡과 모바일 브라우저에서 가장 많이 열린다.

```css
--breakpoint-tablet: 768px;
--breakpoint-desktop: 1024px;
```

- 본문 최대 폭: `calc(100vw - 32px)`
- 버튼 높이: 최소 48px

- 사진은 화면 가장자리까지 확장 가능
- 시네마틱 구간의 스크롤 길이를 데스크톱보다 짧게 설정

### 데스크톱 기준

- 콘텐츠 최대 폭: 1120px
- 본문 텍스트 최대 폭: 720px
- 스토리 사진과 문구를 좌우로 분할 가능
- 과도하게 넓은 빈 공간을 피한다

## 22. 최종 디자인 체크리스트

### 시각

- [ ] 전체 배경에서 한지가 은은하게 느껴지는가
- [ ] 메인 색상 `#A26249`가 기존 청첩장의 정서를 이어가는가
- [ ] 전통 적색과 금색이 과하게 사용되지 않았는가
- [ ] 인장이 실제로 찍힌 듯하지만 글자는 읽히는가
- [ ] 모든 전통 장식에 명확한 역할이 있는가

### 콘텐츠

- [ ] 만남 → 부부 → 가족 → 한국 전통혼례 흐름이 자연스러운가
- [ ] 영준이의 등장이 감정적으로 가장 중요한 구간으로 보이는가
- [ ] 날짜와 장소를 쉽게 찾을 수 있는가
- [ ] 캐나다 결혼식과 한국 전통혼례가 혼동되지 않는가

### 인터랙션

- [ ] 스크롤을 위로 올리면 장면도 자연스럽게 되돌아가는가
- [ ] 영상이 준비되지 않아도 poster가 즉시 표시되는가
- [ ] 애니메이션이 콘텐츠보다 앞서지 않는가
- [ ] 저사양 기기에서 정적 대체 화면이 동작하는가

### 모바일
