# 05. 콘텐츠 및 리소스 인벤토리

## 1. 콘텐츠 톤

### 문장 스타일

- 짧고 차분한 존댓말
- 과한 수식어보다 시간과 관계의 변화를 중심으로 작성
- “결혼”보다 전통혼례 맥락에서는 “혼례”, “자리”, “새로운 시작”을 우선 사용
- 두 사람만의 사랑 이야기에서 끝나지 않고 세 사람의 가족 이야기로 확장
- 한국어가 주 정보이며 영문은 장면 제목과 날짜의 편집 요소로 사용

### 피해야 할 표현

- 상투적인 웨딩 문구를 여러 번 반복
- 긴 시나 인용문
- 가족 구성이나 출산 서사를 당사자 확인 없이 확대 해석
- 실제 관계, 날짜, 지역을 사실처럼 새로 만들어 추가

## 5. 오프닝 미디어 교체 계획

현재 오프닝은 세 장의 이미지를 사용합니다. 각 항목은 최종 단계에서 서로 다른 짧은 영상 한 개와 연결합니다.

| 장면 | 현재 이미지 poster | 최종 영상 | 상태 |
|---|---|---|---|
| 01 밴쿠버 | `vancouver-story.webp` | 밴쿠버 장면 클립 | 영상 미정 |
| 02 캐나다 혼인 | `canada-wedding.webp` | 캐나다 혼인 장면 클립 | 영상 미정 |
| 03 세 가족 | `family-three.webp` | 가족 장면 클립 | 영상 미정 |

영상 수, 길이, 포맷, 재생·스크롤 연동 방식은 실제 자산과 함께 별도로 결정합니다. 영상이 없어도 위 poster만으로 전체 흐름과 핵심 정보를 볼 수 있어야 합니다.

## 6. 실제 프로젝트용 사진 준비 목록

현재 샘플은 사진 3장으로 여러 장면을 재사용합니다. 최종 버전에서는 아래처럼 7–10장을 준비하면 반복감이 줄어듭니다.

1. 밴쿠버를 알아볼 수 있는 두 사람의 와이드 사진
2. 처음 만났던 시기의 자연스러운 사진
3. 함께한 일상 또는 여행 사진 1–2장
4. 캐나다 혼인 장면의 대표 사진
5. 반지·손·서약 등 디테일 사진
6. 임신 또는 아이를 기다리던 시기의 사진 — 공개 여부 확인
7. 영준이와 함께한 가족 사진 2장 이상
8. 마지막 화면용 세 가족 대표 사진
9. 필요 시 양가 가족 사진

### 사진 전달 권장 규격

- 원본 긴 변 2400px 이상
- JPEG, HEIC, PNG 원본 가능
- 웹 배포본은 WebP 또는 AVIF
- 모바일 세로 크롭을 고려해 인물 주변 여백이 있는 원본 우선
- 메신저에서 저장한 저해상도 사본보다 원본 파일 사용
- 파일명 예: `01-vancouver-start.jpg`, `03-canada-ceremony.jpg`

## 7. 이미지별 제작·교체 지시

### 밴쿠버 시작 사진

목적: 이야기의 출발지와 두 사람의 관계를 동시에 보여줍니다.

```text
밴쿠버의 해안 산책로를 나란히 걷는 커플의 뒷모습, 멀리 도시 불빛과 산,
푸른 저녁 하늘, 자연스러운 다큐멘터리 커플 사진, 차분한 채도와 부드러운 필름 대비,
왼쪽 또는 상단에 타이포그래피를 둘 여백, 모바일 세로 크롭에서도 두 인물이 중심에 남는 구도,
로고와 문자 없음
```

### 혼인 디테일 사진

목적: 직접적인 예식 장면보다 “약속”을 상징합니다.

```text
결혼반지를 낀 두 사람이 손을 맞잡은 순간의 클로즈업, 자연광이 들어오는 밝은 실내,
아이보리 드레스와 검은 정장, 사실적인 손과 반지, 따뜻한 중성 색감,
배경은 부드럽게 흐리고 한쪽에 카피를 넣을 여백, 과도한 광택이나 상업 광고 느낌 없음
```

### 가족 사진

목적: 이야기의 핵심 변화와 마지막 감정을 담당합니다.

```text
창가에서 갓난아기를 함께 안고 바라보는 부모, 조용한 아침 자연광,
아이보리와 베이지 계열의 편안한 옷, 친밀하고 꾸미지 않은 가족의 순간,
부드러운 피부톤과 낮은 채도, 모바일 세로 크롭을 위한 안정적인 삼각 구도,
감사 문구를 넣을 하단의 낮은 대비 여백, 로고와 문자 없음
```

### 나무 그림자

```text
투명 배경 위의 사실적인 나뭇가지와 작은 잎 그림자, 한쪽 상단에서 대각선 아래로 뻗는 구도,
가지가 서로 자연스럽게 연결되고 잎의 크기와 농도가 다양함, 부드러운 태양광 그림자,
원형 얼룩이나 흩어진 점처럼 보이지 않음, 회색조, 가로로 긴 고해상도 알파 PNG,
이미지의 오른쪽과 아래쪽으로 갈수록 자연스럽게 옅어짐
```

## 8. 추가 디자인 리소스 목록

### 반드시 필요한 것

- 앱·브라우저 파비콘
- 카카오톡 공유용 대표 이미지 1200×630
- 전통혼례장 지도 또는 지도 연결 URL
- 참석 여부 폼 완료 화면
- 달력 이벤트 정보

### 선택 항목

- 실제 한지 텍스처 1장
- 전통혼례장 외관 사진
- 오시는 길 약도
- 양가 부모님 인사말
- 전통 매듭의 고해상도 실사 또는 3D 리소스
- 배경음악 — 기본 무음, 사용자 선택형

## 10. 콘텐츠 검수 체크리스트

- [ ] 한글·영문 이름의 철자와 띄어쓰기가 일관된다.
- [ ] 모든 날짜의 요일이 실제 달력과 일치한다.
- [ ] 아이 관련 정보의 공개 범위를 확인했다.
- [ ] 장소의 공식 명칭과 도로명 주소를 확인했다.
- [ ] 지도 링크가 모바일 앱 또는 웹에서 열린다.
- [ ] 타임라인의 사건 순서와 사진 촬영 시점이 맞는다.
- [ ] 사진 사용에 필요한 당사자·촬영자 동의를 확인했다.
- [ ] RSVP에 불필요한 개인정보를 요구하지 않는다.
- [ ] 연락처와 계좌정보의 공개 범위를 결정했다.
- [ ] 공유 이미지에 최종 날짜와 이름이 맞다.
