# 00. 확정 결정 및 보류 항목

- 결정 기준일: 2026-07-31
- 적용 대상: 샘플 사이트 v18 및 `docs/` 문서 세트
- 우선순위: 이 문서의 확정 사항이 기존 문서와 새 디자인 가이드의 일반 권장보다 우선합니다.

## 확정 사항

1. 첫 화면은 기존 완자살 창호문과 중앙 로딩 카드를 유지합니다. 카드의 글자형 `혼례` 인장은 `public/wedding/seals/sangho-steph-square-tassel.png` 이미지로 교체합니다.
2. 창호문 첫 장면은 창호·완자살·매듭·한지 카드·나무 그림자를 하나의 물리적 문 세트로 보고 기존 재질과 전통 요소 밀도를 유지합니다.
3. 사이트 전역 브랜드 컬러는 새 디자인 가이드 팔레트를 사용합니다.
4. 창호문에 한해 기존 목재·창호지·매듭 팔레트를 유지합니다. 창호문 밖의 기존 딥 세이지 타임라인은 테라코타 계열로 변경합니다.
5. 한지 질감은 기존의 은은한 강도와 구현 방식을 유지합니다.
6. 전체 서사 흐름은 `창호문 → 시네마틱 오프닝 → 브리지 → 수평 타임라인 → 초대·행사 정보 → RSVP → 엔딩`을 유지합니다.
7. 창호문 다음 시네마틱 오프닝은 최종적으로 하나의 긴 영상이 아니라 여러 개의 짧은 영상을 이어 쓰는 구조로 제작합니다. 현재 단계에서는 각 영상 장면을 이미지로 표시합니다.
8. 데스크톱에서도 최대 480px 모바일 프레임을 가운데 정렬합니다. 1120px 데스크톱 분할 레이아웃은 적용하지 않습니다.
9. UI radius는 새 가이드 토큰을 용도별로 적용합니다.
   - 전체 화면 사진·영상: `0px`
   - 타임라인·인라인 미디어: `8px`
   - 정보·RSVP·Accordion 카드: `16px`
   - 갤러리 lightbox·modal: `28px`
   - 주요 기능 버튼: pill
10. 버튼과 입력의 최소 높이는 `48px`입니다.
11. RSVP는 현재 경험 흐름에 포함합니다. 현재는 진입 카드와 버튼을 유지하며 실제 폼·저장 방식은 후속 단계에서 연결합니다.
12. 기준 Node.js 버전은 `24`입니다.

## 현재 코드 적용 범위

- 선택한 인장 PNG를 창호문 중앙 카드에 표시
- 새 글로벌 팔레트와 테라코타 타임라인 적용
- 타임라인 미디어 `8px`, 정보·RSVP 카드 `16px`, 기능 버튼 pill 및 최소 높이 `48px` 적용
- 오프닝 이미지 3개를 장면 배열로 관리해 나중에 장면별 영상 파일을 연결할 수 있는 뼈대 마련
- 모바일 최대 폭 `480px` 유지
- RSVP 카드 유지
