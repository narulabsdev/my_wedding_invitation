# 00. 확정 결정 및 보류 항목

- 결정 기준일: 2026-07-31
- 적용 대상: 샘플 사이트 v18 및 `docs/` 문서 세트
- 우선순위: 이 문서의 확정 사항이 기존 문서와 새 디자인 가이드의 일반 권장보다 우선합니다.

## 확정 사항

1. 첫 화면은 기존 완자살 창호문과 중앙 로딩 카드를 유지합니다. 카드의 글자형 `혼례` 인장은 `public/wedding/seals/sangho-steph-square-tassel.png` 이미지로 교체합니다.
2. 창호문 첫 장면은 창호·완자살·매듭·한지 카드·나무 그림자를 하나의 물리적 문 세트로 보고 기존 재질과 전통 요소 밀도를 유지합니다.
3. 사이트 전역 브랜드 컬러는 새 디자인 가이드 팔레트를 사용합니다.
4. 창호문에 한해 기존 목재·창호지·매듭 팔레트를 유지합니다. 창호문 밖의 수평 갤러리는 테라코타 계열로 표시합니다.
5. 한지 질감은 기존의 은은한 강도와 구현 방식을 유지합니다.
6. 전체 서사 흐름은 `창호문 열림 → 열린 문 안으로 전진 → 두 사람이 길을 열어주는 1인칭 환영 장면 → 같은 자리에서 영상 1 스크럽 → 첫 데이트 영상 → 영상 위로 갤러리 페이드인 → 수평 갤러리 → 마지막 사진 정지 → 후속 영상 크로스페이드 → 초대·행사 정보 → RSVP → 한복을 입은 가족과 쿠키의 감사 인사`로 구성합니다. 문·영상·갤러리 사이에는 페이지가 아래로 넘어가는 경계를 두지 않습니다.
7. 문이 열린 뒤의 세로 스크롤은 먼저 카메라가 문 안으로 들어가는 전진감에 사용하고, 진입이 끝난 뒤에는 영상의 재생 위치를 제어합니다. 영상은 자동으로 흘러가지 않으며 사용자가 위아래로 움직이면 같은 방향으로 탐색됩니다. 수평 이동은 중간 갤러리에서만 사용합니다.
8. 데스크톱에서도 최대 480px 모바일 프레임을 가운데 정렬합니다. 1120px 데스크톱 분할 레이아웃은 적용하지 않습니다.
9. UI radius는 새 가이드 토큰을 용도별로 적용합니다.
   - 전체 화면 사진·영상: `0px`
   - 갤러리·인라인 미디어: `8px`
   - 정보·RSVP·Accordion 카드: `16px`
   - 갤러리 lightbox·modal: `28px`
   - 주요 기능 버튼: pill
   - 갤러리 사진을 클릭하거나 터치하면 전체 화면 lightbox로 확대
10. 버튼과 입력의 최소 높이는 `48px`입니다.
11. RSVP는 현재 경험 흐름에 포함합니다. 현재는 진입 카드와 버튼을 유지하며 실제 폼·저장 방식은 후속 단계에서 연결합니다.
12. 기준 Node.js 버전은 `24`입니다.

## 현재 코드 적용 범위

- 선택한 인장 PNG를 창호문 중앙 카드에 표시
- 새 글로벌 팔레트와 테라코타 갤러리 적용
- 갤러리 미디어 `8px`, 정보·RSVP 카드 `16px`, 기능 버튼 pill 및 최소 높이 `48px` 적용
- 첫 샘플 MP4를 문 뒤에 직접 배치해 문 열림·진입·영상 스크럽을 하나의 고정 장면으로 연결
- `002.mp4`를 첫 데이트 장면으로 추가하고 전 프레임 키프레임 파생본 `002-scroll.mp4`를 영상 1과 갤러리 사이에 연결
- 나머지 2개의 샘플 MP4도 세로 스크롤 위치와 재생 위치를 동기화
- 첫 영상의 마지막 구간에서 5장 갤러리를 같은 화면에 페이드인한 뒤 세로 입력을 수평 이동으로 변환
- 갤러리 구조와 이야기 카드는 유지하되 임시 샘플 이미지는 제거하고 실제 사진 연결을 대기
- 갤러리 마지막 사진을 추가 스크롤 구간 동안 고정한 뒤 영상 2로 페이드 전환
- 영상 2와 영상 3을 한 sticky 화면 안에서 크로스페이드
- 모바일 최대 폭 `480px` 유지
- RSVP 카드 유지

## 스토리보드 확정·미구현 장면

- 문을 통과한 하객의 1인칭 시점에서 두 사람이 좌우로 길을 열고 카메라가 그 사이를 지나가는 환영 영상
- 한복을 입은 상호·스테프·영준이와 쿠키가 정면에서 감사 인사를 전하는 마지막 영상
- 두 장면 사이의 구체적인 이야기 구성은 추후 확정하며, 현재 코드에는 아직 추가하지 않음
