# 01. 프로젝트 기획서

## 1. 프로젝트 개요

한국 전통혼례의 정서를 현대적인 스크롤 기반 웹 경험으로 재해석한 모바일 청첩장입니다. 정적인 사진 나열이 아니라, 사용자가 손가락으로 세로 스크롤을 계속하는 동안 문이 열리고 영상 재생 위치가 움직이며 중간의 가족 갤러리만 가로로 펼쳐지는 서사형 구성을 목표로 합니다.

초반에는 전통 창호문이 청첩장의 표지가 됩니다. 로딩 자체를 기다리는 시간이 아니라 완자살 창살이 바깥 테두리에서 시작해 중앙으로 이어지는 첫 번째 장면으로 사용합니다. 준비가 끝난 뒤 사용자가 스크롤하면 양쪽 창호문이 열리고, 같은 고정 화면에서 카메라가 문 안으로 들어간 다음 밴쿠버 영상의 재생 위치가 움직입니다.

## 2. 핵심 목표

1. 모바일에서 한 손 스크롤만으로 전체 이야기를 경험할 수 있게 한다.
2. 첫 화면만 보아도 한국 전통혼례 청첩장임을 알아볼 수 있게 한다.
3. 현재는 샘플 영상으로 스크롤 스크럽 구조를 검증하고, 최종적으로 여러 개의 짧은 촬영 영상으로 교체한다.
4. 영상 재생 위치를 제어하는 세로 스크롤 → 중간 수평 갤러리 → 다시 영상 재생을 제어하는 세로 스크롤로 기억에 남는 리듬을 만든다.
5. 장식만 전통적인 화면이 아니라 창호지, 나무, 완자살, 한지, 인장, 매듭의 물성까지 일관되게 표현한다.

## 3. 핵심 콘셉트

### 콘셉트 문장

> 한옥의 문을 열어, 밴쿠버에서 시작된 두 사람의 이야기를 따라가고, 서울의 전통혼례에 도착하는 모바일 청첩장.

### 경험 키워드

- 전통적이되 박물관처럼 무겁지 않음
- 영화적이며, 하나의 긴 영상이 아니라 장면별 이미지에서 복수 영상으로 단계적으로 교체
- 정갈함, 온기, 종이의 질감, 나무의 깊이
- 천천히 열림, 이어짐, 초대, 새로운 장
- 사진은 기록이고 스크롤은 시간의 흐름

### 기준 레퍼런스의 역할

`starter-kit-2ndweek.vercel.app`은 시각 스타일이 아니라 스크롤 서사의 참고 대상입니다. 본 프로젝트에서는 일직선 세로 스크롤을 그대로 따르지 않고, 중간 구간에서 사용자의 세로 입력을 수평 이동으로 변환합니다.

## 4. 사용자 경험 구조

```text
접속
  ↓
완자살 로딩과 창호문 표지
  ↓ 세로 스크롤
양쪽 문이 열림
  ↓
양쪽 문이 열림
  ↓ 같은 고정 화면에서 문 안으로 전진
첫 번째 짧은 영상
(진입 후 세로 스크롤 위치 = 영상 재생 위치)
  ↓ 같은 화면에서 영상 페이드아웃·갤러리 페이드인
  ↓ 세로 스크롤 입력을 수평 이동으로 변환
가족 사진 갤러리
  ↓ 마지막 사진에서 한 번 더 머무름
두 번째·세 번째 짧은 영상 크로스페이드
(세로 스크롤 위치 = 영상 재생 위치)
  ↓
다시 세로 정보 흐름
  ↓
초대 문구 → 일시·장소 → 오시는 길·RSVP → 감사 인사
```

사용자는 어느 구간에서도 옆으로 스와이프할 필요가 없습니다. 손가락은 계속 위로 움직이지만 갤러리 구간에서만 화면 콘텐츠가 왼쪽으로 이동합니다.

## 5. 주요 사용자

- 모바일 메신저로 링크를 받은 가족, 친척, 친구
- 다양한 연령대의 하객
- 한국어를 주로 읽지만 영문 이름·장소 표기도 함께 볼 수 있는 사용자
- 움직임에 민감하거나 기기 성능이 낮은 사용자

## 6. 정보 우선순위

1. 누구의 혼례인지
2. 언제 열리는지
3. 두 사람과 가족의 이야기
4. 어디에서 열리는지
5. 어떻게 찾아오는지
6. 참석 의사를 어떻게 전달하는지

서사적 연출이 정보 전달을 가리면 안 됩니다. 이름·날짜는 첫 장면에서 한 번, 행사 정보 구간에서 다시 한 번 명확하게 보여줍니다.

## 7. 범위

### 현재 샘플에 포함된 항목

- 로딩 진행 상태
- 완자살 생성 애니메이션
- 나무 그림자 페이드인과 흔들림
- 스크롤 연동 양문 열림
- 샘플 영상 3개의 세로 스크롤 기반 재생 위치 제어
- 세로 스크롤 기반 수평 사진 갤러리와 터치·클릭 확대 보기
- 마지막 사진 정지 구간과 후속 영상 간 크로스페이드
- 초대 문구, 행사 일시·장소, 교통·RSVP 카드
- 마지막 가족 사진과 감사 인사
- 모바일 반응형 및 움직임 줄이기 대응
- 선택한 상호·스테프 인장 이미지
- 새 글로벌 팔레트와 테라코타 갤러리
- RSVP 진입 카드

### 실제 프로젝트에서 추가 연결할 항목

- 달력 저장 기능
- 네이버·카카오·구글 지도 연결
- 참석 여부 제출 폼과 저장소
- 연락처, 계좌번호, 마음 전하실 곳 등 필요 정보
- 카카오톡 공유 이미지와 Open Graph 메타데이터
- 실제 사진·이름·행사 정보 최종 교체
- 오프닝 장면별 영상 제작 및 연결
- 개인정보·연락처 노출 범위 결정

## 8. 성공 기준

- 첫 화면에서 전통 창호문의 정체가 즉시 읽힌다.
- 로딩 중 점이나 조각이 임의로 나타나지 않고 선이 테두리에서 중앙까지 연속적으로 그어진다.
- 창살 본체와 그림자가 서로 구분되며 창살이 흐릿해 보이지 않는다.
- 나무 그림자는 상단 한쪽 사선 방향으로만 드리우고 부드럽게 흔들린다.
- 모바일에서 세로 스크롤만으로 수평 갤러리를 완주할 수 있다.
- 문 열림, 영상 스크럽, 갤러리 구간에서 프레임 끊김이 체감되지 않는다.
- 움직임 줄이기 설정에서는 핵심 정보가 정적인 형태로 모두 보인다.
