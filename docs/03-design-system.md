# 03. 디자인 시스템 및 비주얼 가이드

## 1. 디자인 방향

### 한 문장 정의

한국 전통 창호와 한지의 물성을 기반으로, 현대적인 에디토리얼 레이아웃과 사진 중심의 영화적 전환을 결합합니다.

### 피해야 할 방향

- 전통 문양을 작은 아이콘처럼 반복해 붙이는 장식적 접근
- 금색, 빨간색, 검은색을 과도하게 사용한 궁중풍
- 밝은 웨딩 핑크나 서양식 꽃 장식이 중심이 되는 일반 청첩장 스타일
- 창살 본체와 그림자가 구분되지 않을 정도로 진한 입체 효과
- 한지 질감이 노이즈나 먼지처럼 거칠게 보이는 효과
- 모바일 화면에서 글자와 창살이 겹쳐 읽기 어려운 구성

### 컬러 사용 비율

- 한지·아이보리 배경 60%
- 사진과 영상 25%
- 테라코타·짙은 갈색 10%
- 전통 적색·녹색·금색 5%

빨강과 파랑은 의미가 강하므로 매듭과 인장에만 제한적으로 사용합니다. 금색은 광택 장식이 아니라 매듭 중심의 작은 테두리 정도로만 사용합니다.

## 3. 서체

### 한글 제목

- 성격: 붓글씨가 아닌 정갈한 명조
- 현재 샘플: `AppleMyungjo`, `Batang`, `Georgia`, `serif`
- 권장: 실제 배포에서는 라이선스가 명확한 한글 명조 웹폰트 한 종을 내장하거나 안정적인 CDN으로 제공
- 굵기: 400–600
- 행간: 1.35–1.72
- 자간: 큰 제목은 약간 좁게, 작은 전통 문구는 넓게

### 한글 본문

- 현재 샘플: `Apple SD Gothic Neo`, `Noto Sans KR`, `Pretendard`, `Arial`, `sans-serif`
- 권장 굵기: 400–600
- 모바일 본문 크기: 13–16px
- 긴 문장 행간: 1.8–2.0

### 영문·숫자

- 현재 샘플: `Georgia`, `Times New Roman`, `serif`
- 역할: 날짜, 도시, 챕터, 이름
- 대문자 라벨 자간: `0.18em–0.32em`
- 날짜 숫자는 크게 사용하되 한글 정보보다 위계가 과도하지 않게 조절

### 가독성 원칙

- 창호문 위의 초대장은 반투명 한지 패널을 사용해 창살과 텍스트가 직접 충돌하지 않게 합니다.
- 사진 위의 흰 글자는 검은 반투명 그라데이션 또는 그림자로 대비를 확보합니다.
- 얇은 명조체를 13px 이하로 사용하지 않습니다.
- 중요한 이름·날짜에는 최소 4.5:1에 가까운 명도 대비를 확보합니다.

## 4. 완자살 형태

### 구조

샘플의 완자살은 7×15 단위의 세로 패널을 기준으로 만든 직교 격자입니다. 좌우 대칭 셀과 상하로 반복되는 큰 중앙 창을 조합해, 정사각 격자 안에 꺾이고 돌아가는 `卍` 계열의 리듬이 읽히도록 구성합니다.

- 외곽 프레임: 가장 두껍고 어두운 선
- 내부 창살: 외곽보다 가늘지만 충분히 선명한 갈색
- 창호지: 따뜻한 미색, 아주 약한 종이 결
- 선 끝: 둥근 점이 생기지 않도록 평평한 `butt` 형태
- 모서리: 직각 `miter` 형태
- 오른쪽 패널: 왼쪽 패널을 수평 반전해 양문 대칭 구성

### 입체감

창살 본체를 흐리게 만들지 않고, 본체 뒤에 짧고 부드러운 그림자만 추가합니다.

현재 샘플의 SVG 그림자 기준:

```text
offset x: 0.05 unit
offset y: 0.07 unit
blur: 0.032 unit
color: #2D1B10
opacity: 0.40
```

그림자가 또 하나의 창살처럼 읽히면 오프셋·불투명도·블러를 먼저 낮춥니다. 본체의 불투명도를 낮추는 방식으로 해결하지 않습니다.

## 5. 한지와 나무 재질

### 창호지

- 기본색: `#EEE3CB` 부근
- 중앙은 조금 밝고 가장자리는 나무 프레임의 반사로 약간 어두움
- 질감은 5–7px 간격의 아주 작은 불규칙 패턴 정도로 제한
- 종이 얼룩, 접힌 자국, 찢어진 가장자리 표현은 사용하지 않음

### 나무

- 표면은 짙은 갈색 그라데이션으로 두께를 표현
- 외곽 프레임 안쪽에 얇은 밝은 갈색 라인을 두어 모서리 반사 표현
- 강한 광택보다 오래된 목재의 무광 질감
- 문 전체 그림자는 화면 가장자리로 퍼지되 콘텐츠를 탁하게 만들지 않음

## 6. 나무 그림자

### 구도

- 시작점: 화면 상단 왼쪽 바깥
- 진행 방향: 왼쪽 위에서 오른쪽 아래로 내려오는 한쪽 사선
- 도달 범위: 상단 전체를 덮지 않고 화면 왼쪽 중반까지
- 형태: 작은 원 여러 개가 아니라 가지와 잎이 연결된 자연스러운 실루엣
- 색: 회색 단색 리소스를 `multiply`로 창호지에 혼합
- 가장자리: 마스크로 서서히 사라져 잘린 이미지처럼 보이지 않게 함

### 리소스 조건

- 투명 배경 PNG 또는 알파가 있는 WebP
- 가로로 긴 구도
- 잎 크기의 다양성과 가지 연결이 분명할 것
- 하이라이트나 실제 나무색 없이 그림자 정보만 포함
- 현재 샘플: 1896×830, 8-bit grayscale PNG

## 7. 사진 방향

### 공통 보정

- 채도를 약 70–85% 수준으로 절제
- 너무 차갑거나 노란 사진은 중성에 가깝게 통일
- 피부색은 자연스럽게 유지
- 하이라이트를 줄이고 어두운 영역을 살짝 올려 부드러운 필름 톤 형성
- 사진마다 강한 프리셋을 적용하기보다 전체 이야기의 색온도만 맞춤

### 장면별 사진 조건

| 장면 | 권장 구도 | 여백 |
|---|---|---|
| 밴쿠버 시작 | 두 사람이 함께 걷는 뒷모습, 장소가 읽히는 와이드 컷 | 하늘·수면 쪽 텍스트 여백 |
| 캐나다 혼인 | 손, 반지, 약속을 상징하는 클로즈업 | 한쪽에 카피를 놓을 낮은 대비 영역 |
| 가족 | 부모와 아이가 한 프레임에 안정적으로 들어오는 중경 | 화면 아래 또는 우측 여백 |
| 엔딩 | 관계와 표정이 전달되는 대표 가족 사진 | 하단 감사 문구를 위한 어두운 영역 |

### AI 이미지 제작 프롬프트 골격

실제 인물을 재현해야 하는 최종 리소스에는 반드시 당사자 사진을 참조로 사용합니다. 아래 골격은 분위기와 구도만 정의합니다.

```text
[인물·관계와 행동], [구체적인 장소], 자연광 기반의 다큐멘터리 웨딩 사진,
절제된 채도, 부드러운 필름 대비, 따뜻한 아이보리와 테라코타 톤,
과한 포즈 없이 자연스러운 순간, 모바일 세로 크롭을 고려한 중심 구도,
[텍스트를 둘 위치]에 충분한 낮은 대비 여백, 사실적인 피부와 직물 질감,
로고·문자·워터마크 없음
```

## 8. 레이아웃

### 모바일 프레임

- 콘텐츠 최대 너비: 480px
- 더 넓은 화면: 가운데 정렬, 바깥은 짙은 배경
- 좌우 기본 여백: 24–28px
- 카드형 사진 너비: 화면의 약 74%
- 타임라인 한 장 너비: 화면의 약 88%
- 버튼과 입력 터치 영역: 최소 높이 48px
- 하단 고정 요소는 `safe-area-inset-bottom` 고려

### 여백 리듬

- 전환 문장 구간: 한 화면에 한 메시지만 놓일 정도로 넉넉하게
- 행사 정보: 중앙 정렬과 큰 숫자로 명확하게
- 세부 정보 카드: 모바일에서 한 열
- 사진 위 카피: 가장자리에서 최소 24px 확보

## 9. UI 구성요소

- 첫 화면 인장: `public/wedding/seals/sangho-steph-square-tassel.png`
- 전통 매듭: 붉은색·청색 루프, 중앙의 작은 금색 이중 테두리
- 라벨: 9–11px 영문 대문자, 넓은 자간
- 진행선: 1px, 낮은 대비의 바탕선 위에 밝은 진행선
- 버튼: 캡슐형, 투명 배경, 1px 테두리; hover·focus 시 전경/배경 반전
- 전체 화면 사진·영상: `0px`
- 타임라인·인라인 미디어: `8px`
- 정보·RSVP·Accordion 카드: `16px`
- 갤러리 lightbox·modal: `28px`
- 주요 기능 버튼: pill, 최소 높이 `48px`

## 10. 디자인 QA 체크리스트

- [ ] 첫 화면에서 완자살의 패턴이 완자형으로 읽힌다.
- [ ] 창살 본체가 그림자 때문에 흐릿하지 않다.
- [ ] 창호지 위 초대장 글자가 모든 화면에서 읽힌다.
- [ ] 나무 그림자가 상단 왼쪽 사선 한 방향으로만 보인다.
- [ ] 사진의 색감이 장면마다 갑자기 달라지지 않는다.
- [ ] 가로 타임라인에서도 현재 카드의 초점이 분명하다.
- [ ] 한글 명조와 영문 세리프의 위계가 자연스럽다.
- [ ] 모바일 360px 너비에서도 문구가 잘리거나 과하게 줄바꿈되지 않는다.
- [ ] 전통 요소가 정보 버튼의 사용성을 방해하지 않는다.
