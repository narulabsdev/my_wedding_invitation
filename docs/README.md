## 이 문서의 사용법

- 모든 참여자: 먼저 `00`에서 확정 사항과 보류 범위를 확인합니다.
- 기획자·당사자: `01`, `02`, `05`에서 내용과 행사 정보를 확정합니다.
- 디자이너: `02`, `03`, `04`를 기준으로 화면과 전환 장면을 설계합니다.
- 프런트엔드 개발자: `04`, `06`을 구현 명세로 사용합니다.
- 사진·영상·AI 콘텐츠 제작자: `02`, `03`, `05`의 장면 설명과 이미지 가이드를 프롬프트에 사용합니다.

## 상태 표기

- **확정 방향**: 대화에서 합의된 핵심 콘셉트입니다.
- **샘플 구현**: 현재 데모에 들어간 수치·문구·리소스입니다.
- **확인 필요**: 실제 청첩장 제작 전에 당사자가 확정해야 합니다.

> 행사 일시, 장소, 주소, 이름 표기와 버튼 연결은 현재 샘플 값이 포함되어 있으므로 실제 배포 전에 반드시 다시 확인해야 합니다.
